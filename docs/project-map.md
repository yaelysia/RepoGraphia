# 项目级代码地图（投影版本 1）

这是现有代码图的程序化视图，不是业务功能归纳。本轮分析规则仍为 4，未解析函数数量不作为这轮的开发目标。

## 浏览方式

新生成的 index.html 默认打开项目地图。先展示实际目录直接子级；单击目录节点或左侧路径，右侧查看该区域的关联，再点击“进入目录”。文件节点提供“查看文件与函数”，进入既有符号/源码/来源追踪界面。“返回项目地图”回到上次目录，面包屑可以回到任何祖先目录。

箭头表示有向静态关系。点击聚合连线或下方连接记录，展开每页 25 条的原始证据；点击某条查看解析依据、源码、候选路径，返回时保留聚合选择及页码。

顶部项目指标覆盖完整分析快照，含测试。项目地图默认隐藏测试路径，本层的文件/关系统计单独显示筛选范围。左侧搜索在地图模式下筛选当前层级路径；切换“文件”或“函数/类”可全项目搜索。

没有被索引的 Python/PowerShell 等文件以未索引路径保留，不产生虚构实现或跨语言连线。未识别目录/忽略目录不视为已完整扫描，详细范围仍见“分析边界”。

## 统计与证据约束

- 聚合连接按有向子级对组织，内部保存 kind/status/typeOnly 分项。导入、接口、继承、回调传入不改写成函数调用；紫色虚线表示混合状态，不是确定关系。
- 单条关系有多个候选目标落在同一组时只计一次；落在不同组时可以属于多组。各组/类别计数不可直接相加为总调用数。
- 折叠后的内部关系、当前目录外的入边/出边、无目标关系、缺失端点和含隐藏测试目标的记录，均有单独计数与证据入口。
- 隐藏测试只影响地图展示，不修改原始关系、候选来源和源码。显式点开原始证据仍能查看完整目标集合。
- 未索引路径与无连线节点保留。无可见连线不意味着运行时没有关系。
- 投影及分页使用同一份 CodeGraph；不会重新运行 TypeScript 或要求 AI 解释关系。

## 预算

默认画布最多 12 个子级节点、24 条聚合连接；可逐步增加至 60/240。超过预算会标明截断，左侧导航和下方连接列表不受这个画布截断影响。导航当前层级最多装入 1000 个子级（每页 60），连接列表最多装入 5000 条（每页 30）；这些额外上限也明确显示。更大目录可用全项目文件搜索继续定位。

关系证据每页 25 条。CLI/library 支持显式预算；不存在隐藏的“完整关系图”声明。大图布局暂为确定性网格/环形，没有语义布局、自由拖拽、自动功能命名或运行时流程保证。

## 程序接口

```sh
node dist/cli.js query reports/codex-monitor/graph.json map
node dist/cli.js query reports/codex-monitor/graph.json map src --kind import
node dist/cli.js query reports/codex-monitor/graph.json map-records . --from electron --to src --limit 25
node dist/cli.js query reports/codex-monitor/graph.json map-records src --category outside
```

路径使用报告中的相对路径；`.` 为根目录。`map` 结果带 projectionRevision、原始 snapshot、groups、links、summary、boundary；`map-records` 返回完整原始 relations 及 offset/limit/nextOffset。不存在的目录、非法路径、单侧方向选择和非法预算报错，不猜测意图。

`src/project-map.ts` 导出自包含 createProjectMapApi 工厂。CLI 直接调用；HTML 将编译后的同一工厂和轻量 UI 适配器内联，继续使用整段脚本哈希 CSP。没有另写浏览器版分类器，也不引入图数据库或前端打包依赖。

## 验证

28 项手写聚合/CLI 正反例覆盖多目标去重、同名符号、类型关系、外部/未知边界、筛选、分页、空项目、恶意对象键和千节点循环。另有独立真实源码夹具的 4 项端到端标注测试：预期的完整目录关系矩阵由人工写定，不从投影生成。

真实 Codex-Monitor CI 除原有 30 项交互检查外增加项目地图检查；Python 独立按原始节点/边 ID 核算根目录矩阵。对照 CP9 时，files/nodes/relations/coverage/diagnostics 必须完全一致。两套工具安装目录不同可能影响编译器输入路径敏感的 snapshot，因此不把两个工具的 snapshot 字符串相同当作必要条件；每张投影必须严格关联它自己的原始 snapshot。

这些是选定静态事实、聚合和交互验证，不是多个生产项目上的全局准确率/召回率评测。功能语义、Git 变更、Agent 路线图、增量索引和动态追踪尚未实现。
