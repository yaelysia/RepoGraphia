## 发现的问题与修复

- 全树预留跨度会在折叠后形成大块空白：同一中文 DOM 尺寸对照后选择可见投影，详见 [CP47](CP47-function-tree-prototype.md)。
- 同范围搜索和跨范围反复访问覆盖先前相机/展开：历史记录改为复制完整阅读快照，并增加先复现后修复的回归。
- 固定 viewport 高度会挤出底部缩放工具栏：改为按容器剩余空间布局，原 shell 可达性断言保持不变并通过。
- 功能建设隐藏地图 iframe 后触发零宽测量：可见后再量测，不放宽几何合法性约束；完整提案流程复跑为零异常。
- 原工作台和导出脚本假定返回总览后所有卡片都在视区：改为通过真实全局搜索定位再点击。原审阅、证据、导出断言全部保留，没有用 force-click 绕过可达性。
